- `pause` keeps the active record. `resume_task` (line 133 onward) selects `previous_task[&#39;riskClass&#39;]` and exposes no risk/baseline amendment argument.

- `begin --baseline` validates `.sdlc/schemas/accepted-baseline.schema.json`, whose required `issue` object requires a GitHub Issue number, URL and body. The only snapshot command captures a GitHub Issue.
