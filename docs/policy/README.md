# Ontology editing policy

The rules that ontology changes must satisfy are owned by the SHACL graphs in [`policy/`](../../policy/); this page only points to them.

| What                                         | Where                                                                                                                                                                                       |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Editing-policy shapes (source of truth)      | [`policy/editing-policy.ttl`](../../policy/editing-policy.ttl) and the sibling `*-policy.ttl` and `*-shapes.ttl` graphs in [`policy/`](../../policy/)                                       |
| Active module set that publication qualifies | [`policy/activation.ttl`](../../policy/activation.ttl)                                                                                                                                      |
| Authority snapshots the rules reference      | [`policy/authorities/`](../../policy/authorities/)                                                                                                                                          |
| Human-readable projection of the rules       | [Editing-Policy.generated.md](Editing-Policy.generated.md) — generated by `npm run generate:editing-policy`; `npm run check:editing-policy` fails when it is stale. Do not edit it by hand. |
| Validator                                    | `scripts/validate_ontologies.py` (`npm run validate:ontologies`), run by the pre-commit hook, GitHub Actions and directly; `scripts/ontology_policy/` implements the policy engine          |
| Publication gate                             | `scripts/ontology_policy/publication.py`, consumed by `scripts/upload_to_s3.py`; requires a current `--purpose latest-active` receipt                                                       |
| Migration evidence                           | [migration-evidence.md](migration-evidence.md) — the record of the SHACL policy cutover; historical, not a second policy                                                                    |

Commands are listed in the [development guide](../development.md#verification-commands).
Conformance to the shapes is necessary, not sufficient: source interpretation, intended compatibility and definitions are reviewed by people.
