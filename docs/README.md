## Implementation sources

The [September 2026 SDLC improvement sources](plans/sdlc-improvements/README.md)
group the overall plan and nine work packages by responsibility. Companion
contracts, examples and planning checks remain with the plan they explain.
Their index distinguishes historical proposals from the implemented outcome
and maps the original delivery paths to their preserved locations.

Existing documents outside these initiative folders have not been reorganized
as part of preserving the SDLC sources.
