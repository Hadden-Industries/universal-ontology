## Historical material and current navigation

Plans and companion Markdown documents now use the organized paths. Their preparation dates, proposed status, acceptance boundaries and reported outcomes have not been upgraded or relabeled. Proposed schemas and policy amendments are historical design inputs, not operational configuration.

JSON observations, examples, schemas, reproduction commands and Python planning probes retain their original bytes. References inside these historical artifacts therefore retain delivery-era names. The Python probes are historical recipes, not maintained commands for validating this reorganized package; do not execute them as routine controls.

`original-delivery-manifest.json` and `original-delivery.sha256` describe the original delivery names and bytes, not the edited Markdown or current layout. Their old hashes are deliberately unchanged. The table below maps those identities to current files. It is a navigation/provenance record, not evidence of approval.

WP6 planning checks have their own descriptive directory. Its README is at the work-package root because it introduces the whole package.
